# ESCAPE — Weekend Trip Planner

A lightweight, responsive React web application designed to help users quickly plan and organize weekend getaways by filtering destinations, budgets, and itineraries.

## Tech Stack
* **Frontend**: React 18, HTML5, CSS3
* **Build Tool**: React Scripts
* **Deployment**: Vercel

## Features
* Interactive trip search form supporting origin and budget parameters.
* Automated day-by-day weekend itinerary view.
* Fully responsive layout optimized for mobile and desktop screens.
